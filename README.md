SpamServices
Описание проекта
SpamServices — это веб-приложение на Django, разработанное для создания и управления массовыми рассылками. Оно предоставляет функционал для управления клиентами, сообщениями и самими рассылками, а также включает ролевую систему для обычных пользователей и менеджеров. Проект обеспечивает ведение журнала рассылок и отчетности, а также функции безопасности, такие как подтверждение email и сброс пароля.

Основные возможности
Управление рассылками: Создание, просмотр, редактирование, удаление и запуск рассылок с различными статусами (создана, запущена, завершена) и периодичностью (ежедневно, еженедельно, ежемесячно).

Управление клиентами: Добавление, просмотр, редактирование и удаление клиентских контактов.

Управление сообщениями: Создание, просмотр, редактирование и удаление шаблонов сообщений для рассылок.

Аутентификация и авторизация:

Регистрация пользователей с подтверждением Email.

Вход/выход из системы.

Функция сброса пароля.

Ролевая система:

Обычные пользователи: Могут управлять только своими рассылками, клиентами и сообщениями.

Менеджеры: Могут просматривать все рассылки, клиентов, сообщения, журнал рассылок и отчеты. Могут изменять статус рассылок (активировать, приостанавливать, завершать). Могут блокировать/разблокировать других пользователей сервиса. Не могут редактировать или удалять данные, созданные другими пользователями.

Журналирование и отчетность:

Ведение журнала всех попыток рассылок с указанием статуса и ответа сервера.

Генерация отчетов по рассылкам с информацией об успешных и неуспешных попытках.

Оптимизация производительности: Внедрено кеширование для повышения скорости загрузки главной страницы.

Используемые технологии
Backend: Python, Django 5.2.4

База данных: PostgreSQL (для разработки используется SQLite)

Фронтенд: HTML, CSS (Bootstrap 5.3), JavaScript

Управление секретами: python-decouple

Линтинг кода: Flake8

SMTP-сервер: Для отправки писем (подтверждение email, сброс пароля)

Установка и запуск
Следуйте этим инструкциям, чтобы развернуть и запустить проект на вашем локальном компьютере.

Предварительные требования
Python 3.10+

PostgreSQL (или используйте SQLite по умолчанию)

Шаги установки
Клонируйте репозиторий:

git clone https://github.com/Doczadrot/MessageServices
cd MessageServices

Если у вас нет репозитория, просто перейдите в корневую директорию проекта.

Создайте и активируйте виртуальное окружение:

python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows

Установите зависимости:

pip install -r requirements.txt
# Или вручную, если requirements.txt нет:
# pip install django psycopg2-binary python-decouple django-widget-tweaks

Настройте переменные окружения:
Создайте файл .env в корневой директории проекта (рядом с manage.py) и добавьте следующие строки, заполнив их своими данными:

DB_NAME=project3
DB_USER=postgres
DB_PASSWORD=YOUR_DB_PASSWORD # ЗАМЕНИТЕ НА ВАШ ПАРОЛЬ ОТ БАЗЫ ДАННЫХ
DB_HOST=localhost
DB_PORT=5432

# Настройки для почты (пример с Yandex SMTP)
EMAIL_HOST=smtp.yandex.com
EMAIL_PORT=465
EMAIL_USE_SSL=True
EMAIL_HOST_USER=your_email@yandex.com
EMAIL_HOST_PASSWORD=YOUR_EMAIL_APP_PASSWORD # ЗАМЕНИТЕ НА ВАШ ПАРОЛЬ ПРИЛОЖЕНИЯ

Важно: YOUR_EMAIL_APP_PASSWORD — это пароль приложения, который вы должны сгенерировать в настройках безопасности вашей почты (не основной пароль от аккаунта).

Настройте базу данных:
Убедитесь, что у вас установлен и запущен PostgreSQL, и что пользователь postgres может подключаться к базе данных project3 с указанным паролем. Если пользователь postgres не существует или его пароль отличается, создайте его в PostgreSQL:

sudo -u postgres psql
CREATE ROLE postgres WITH LOGIN PASSWORD 'YOUR_DB_PASSWORD'; # ЗАМЕНИТЕ НА ВАШ ПАРОЛЬ
ALTER ROLE postgres CREATEDB;
\q

Возможно, также потребуется настроить pg_hba.conf для аутентификации md5 для локальных подключений.

Выполните миграции базы данных:

python manage.py migrate

Создайте суперпользователя (для доступа к админ-панели):

python manage.py createsuperuser

Следуйте инструкциям в терминале.

Запустите сервер разработки:

python manage.py runserver

Приложение будет доступно по адресу: http://127.0.0.1:8000/

Использование
Доступ к функциям
Обычный пользователь: Зарегистрируйтесь на сайте и подтвердите свой Email. Вы получите доступ к своим рассылкам, клиентам и сообщениям.

Менеджер:

Войдите в админ-панель (http://127.0.0.1:8000/admin/) под суперпользователем.

Перейдите в раздел "Пользователи".

Выберите существующего пользователя или создайте нового.

Установите флажок "Статус персонала" (Staff status).

В разделе "Группы" добавьте пользователя в группу "Менеджеры".

Войдите на сайт под учетной записью этого пользователя, чтобы получить доступ к функциям менеджера (просмотр всех данных, управление статусами рассылок, блокировка пользователей).

Линтинг кода (Flake8)
Чтобы проверить ваш код на стилистические ошибки и потенциальные проблемы:

Установите Flake8: pip install flake8

Создайте файл setup.cfg в корне проекта:

[flake8]
exclude =
    .git,
    __pycache__,
    .venv,
    env,
    migrations,
    settings.py
max-line-length = 120

Запустите проверку: flake8 .
